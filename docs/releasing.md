# GitHub发布准备
本文件用于后续版本发布检查。代码仓库的发布与文章发布分别授权；文章及真实运行数据不属于代码上传范围。
1. 阅读README的兼容与数据说明，确认仓库名、账号、公开范围及MIT许可证。
2. 执行 tests，再执行 tools/release_check.py。检查将要上传的实际目录。
3. 只上传本仓库；不能上传CODEX_HOME、历史运行根目录、work、缓存、真实报告或日志。不要用git add整个上级目录。
4. GitHub Actions仅运行模拟测试，不注入模型账户或桌面连接凭据。
5. 公开问题反馈使用虚构ID、脱敏异常和版本号；不贴完整聊天或连接变量。
